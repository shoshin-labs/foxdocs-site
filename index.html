The loop

Not generate and hope.

The file only moves when you do. Reviews do not overwrite in silence. They cut a version.

See the full sequence

01

Import

Drop the policy you already have. Foxdocs takes the file, not a blank page.

02

Overhaul

Rewrite the whole document in one run when the current draft is not fit.

03

Plan and execute

An improvement plan lists the changes. You accept them. Then you run the plan.

04

Review on a cycle

Periodic reviews check it still complies. Each review cuts a new version.

05

Publish

The live version is the one you sign off. Timeline and activity stay with it.

06

Distribute

Send it to the team. Employees acknowledge it. That is separate from who can edit.
