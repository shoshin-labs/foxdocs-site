The loop

Five steps. One document. A trail you can show.

This is the path a file takes in the app. The words below are the words on the screen: Versions, Timeline, Distributions, Shares, Export, Activity.

  1. 01

    Review

    Open the document. Run Analyse & Review. The default sub-agents are the ones you set under Settings → Organisation: Fidelity and Completeness under Integrity; Mechanics and Style under Language.

    Start AnalysisReviewsScore 8.9/10

    You get a scored reading of this version. Findings are coverage, risk, and missing structure, not a single “AI said so”.

  2. 02

    Improvement plan

    Choose Improve document. That generates a structured plan before anything is written into the file. You set scope. Then you work the proposals one by one: accept or reject.

    Improvement PlansAccept / reject

    Applied proposals save as a new version. The audit trail keeps what landed. Leftover proposals from the old version stay off the new one until you run a fresh plan.

  3. 03

    Overhaul

    If the document is the wrong shape, Start Overhaul. It keeps your content and reorganises against the document type template. Use this instead of a long plan when the skeleton is the problem.

    Overhauls sit beside Reviews and Improvement Plans, under Documents.

  4. 04

    Publish

    When the version is ready, publish it. Classification sits on that copy. The document tabs do the rest of the record-keeping.

    Tab What you see
    Versions Draft and published copies, in order.
    Timeline Version created, version published, and actions such as signatures invalidated when a new version goes out.
    Activity Who did what on this file.
    Shares People invited to the document.
    Export Branded PDF summary, or Excel with version history, section-level changes, and approval status.
  5. 05

    Distribute

    Open the Distributions tab. Create a distribution to send this document to employees for acknowledgement. That list is the Employees register, not Users.

    DistributionsEmployeesImport CSV

    Add staff by name, email, and position. Turn alerts on if they should hear about updates. Acknowledgements attach to the published version. If you publish again, signatures can be invalidated. Then you distribute the new one.
